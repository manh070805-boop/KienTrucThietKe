# KienTrucThietKe

Repo phục vụ dự án môn Kiến trúc và Thiết kế phần mềm.

## Trạng thái hiện tại

Dự án đang trong giai đoạn khởi tạo và thiết lập quy trình làm việc nhóm.

## Quy trình đóng góp

1. Tạo Issue mô tả nhiệm vụ và tiêu chí hoàn thành.
2. Nhận nhiệm vụ bằng Assignee.
3. Cập nhật main và tạo nhánh riêng cho nhiệm vụ.
4. Thực hiện thay đổi, tự kiểm tra và tạo commit.
5. Push nhánh lên GitHub và mở Pull Request.
6. Review và chỉnh sửa theo góp ý.
7. Merge vào main khi đạt yêu cầu.

## Quy ước đặt tên nhánh

- feat/<so-issue>-<noi-dung>: thêm chức năng.
- fix/<so-issue>-<noi-dung>: sửa lỗi.
- docs/<so-issue>-<noi-dung>: cập nhật tài liệu.

Ví dụ: docs/1-update-readme.
